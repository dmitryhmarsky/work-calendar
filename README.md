# Учёт часов

Календарь учёта рабочих часов для Android. Ввод часов за каждый день, итоги по неделе и месяцу, норма, ставка, отчёт в буфер обмена. Данные хранятся на устройстве.

## Скачать APK

1. Откройте на телефоне страницу **Releases** этого репозитория.
2. Скачайте `work-calendar.apk` из релиза «Последняя сборка».
3. Откройте файл и разрешите установку из этого источника, если Android попросит.

APK собирается автоматически при каждом коммите в `main` (вкладка **Actions**, workflow «Build APK»). Каждую сборку можно скачать и как артефакт запуска.

Новая версия устанавливается поверх старой, данные остаются, потому что сборки подписаны одним постоянным ключом (`android/app/debug.keystore`).

## Как устроен проект

- `www/index.html` — всё приложение в одном файле (HTML, CSS, JS).
- `android/` — Android-проект на Capacitor, в него при сборке копируется `www/`.
- `.github/workflows/build-apk.yml` — сборка APK на GitHub Actions.

Чтобы изменить приложение, правьте `www/index.html` и делайте коммит в `main`. Сборка запустится сама.

## Локальная сборка

Нужны Node 22, JDK 21 и Android SDK 35.

```bash
npm ci
npm run build:apk
# android/app/build/outputs/apk/debug/app-debug.apk
```
